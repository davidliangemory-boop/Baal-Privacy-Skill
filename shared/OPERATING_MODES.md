# Operating Modes — v0.5

The same legal-research architecture should behave differently depending on the user's decision need. Select one mode before research.

## RAPID_SCREEN
Use for an initial internal answer where speed matters.
- Goal: identify likely answer, dispositive facts, major uncertainty, and next source to check.
- Minimum source standard: current primary law + one authoritative interpretation where available.
- Do not exhaustively collect cases.
- Output target: short executive conclusion + issue tree + red flags + evidence gaps.
- Stop when the business can decide whether escalation is needed.

## STANDARD_ANALYSIS
Default mode for in-house legal advice.
- Verify all outcome-determinative propositions.
- Search counter-authority for contested points.
- Resolve material fact analogies through official guidance/cases.
- Include Horizon if future change could affect the decision within 6–24 months.

## FORMAL_OPINION_SUPPORT
Use to support external-counsel or board-level work; not a substitute for jurisdiction-qualified counsel.
- Primary/official authority required for all core legal propositions where available.
- Pinpoint citations and temporal validation required.
- Material assumptions and reliance limitations explicit.
- Search adverse/counter-authority.
- Separate legal conclusion, factual representation, inference, and recommendation.
- Research log and unresolved source gaps required.

## MULTI_JURISDICTION_MATRIX
Use for comparing two or more jurisdictions.
- Normalise factual questions, not legal doctrine.
- Identify common baseline, local overlay, stricter/unique requirements, and uncertain points.
- Avoid false equivalence across local concepts.

## DAILY_ISSUE_BRIEF
Use for a recurring brief on one concrete issue.
Each run must answer four questions:
1. **Source Base Delta** — any new/updated authoritative source?
2. **Framework Delta** — did the legal test/issue tree change?
3. **Issue-Resolution Delta** — any new FAQ, decision, judgment, enforcement action or factual analogue that changes a specific proposition?
4. **Horizon Delta** — any consultation, draft, proposed law, work programme, pending appeal, or policy signal changing future risk?

Output only deltas plus the current conclusion. If none, say so. Do not rebuild the whole memo daily.

## DEEP_RESEARCH
Use when the issue is novel, conflicted, high exposure, or source coverage is weak.
- Broaden sources and jurisdictions where legally relevant.
- Trace citations backward to primary authority.
- Search later history and treatment.
- Search counterexamples and regulator divergence.
- Preserve unresolved conflict rather than forcing a single answer.
